The project

A chat agent that can hold context.

The client needed an AI agent that could handle incoming chat messages intelligently — not just respond with static answers, but actually remember context across the conversation and pull in real-time information from the web when needed.

The key challenge was connecting three distinct capabilities into one seamless agent: natural language understanding via OpenAI, persistent conversation memory, and live web search — all triggered automatically when a chat message arrives.

I built the full workflow in n8n — a clean 3-component AI agent architecture that handles everything from trigger to response without any manual intervention.

What the system needed to do

Bring context, reasoning, and current web information into the same response flow—without forcing a person to monitor each incoming message.

How it works

One workflow. Six working parts.

The original build connects the trigger, agent logic, model, memory, live search, and response path. Each part has one clear responsibility inside the automation.

01 · TRIGGER

When chat message received

The workflow fires automatically every time a new chat message comes in — no polling, no delays. The message is passed directly to the AI Agent node for processing.

02 · ORCHESTRATION

AI Agent node

The core of the system — an n8n AI Agent node that orchestrates the OpenAI model, memory, and tools. It decides when to search the web, recall prior context, and formulate the best response.

03 · LANGUAGE

OpenAI chat model

GPT powers the agent's language understanding and response generation. The model receives the full conversation context and produces natural, intelligent replies tailored to the user's message.

04 · CONTEXT

Simple memory

The agent remembers previous messages in the conversation — so follow-up questions work naturally. No need to repeat context; the agent knows what was already discussed.

05 · LIVE DATA

SerpAPI web search

When the agent needs current information, it automatically queries SerpAPI for real-time search results — then incorporates those findings into its response.

06 · DELIVERY

Fully autonomous

The entire pipeline runs without human involvement. From message received to response delivered — the agent handles everything: understanding, searching, remembering, and replying.
