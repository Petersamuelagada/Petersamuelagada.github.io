The project

A content pipeline built to run without a queue.

The client needed an automated system to monitor an RSS feed (Suffolk events), process incoming items with AI, format the data correctly, and publish to their platform — all without any human involvement.

The challenge was building a reliable pipeline that could handle the nuances of RSS data: inconsistent date formats, varying content structures, and the need for intelligent summarisation before publishing — not just raw data passthrough.

I built the full workflow in Pabbly Connect — 9 steps from RSS trigger to API publish, with 3 ChatGPT processing nodes, intelligent time delay, and 3 DateTime formatters ensuring clean, consistent data output every time.

What the pipeline needed to do

Monitor incoming event data, make it readable, preserve clean time information, and publish it consistently without manual checking or formatting.

How it works

From incoming item to published event.

The original build is a nine-step Pabbly Connect workflow. The key processing stages below show how the RSS item becomes structured, AI-summarised content ready for publication.

01 · INTAKE

RSS feed trigger

The workflow fires automatically every time a new item appears in the RSS feed — no manual checking required. Each new event immediately enters the processing pipeline.

02 · PROCESS

ChatGPT node 1

First OpenAI call processes the raw RSS item — extracting key event details, cleaning up the content, and structuring it for the next stage. Uses Text Input Response API for fast processing.

03 · WRITE

ChatGPT node 2

Second OpenAI call generates a polished, human-readable event summary or description — transforming raw RSS data into properly formatted, publishable content.

04 · PACE

Delay node

An intelligent time delay between processing and publishing — preventing API rate limit issues and ensuring the pipeline processes items at a controlled, reliable pace.

05 · VERIFY

ChatGPT node 3

Third OpenAI call retrieves the final processed response by ID — ensuring the complete, verified output is ready before any date formatting or API publishing occurs.

06 · FORMAT

3x DateTime formatters

Three DateTime nodes handle date formatting: Format Date Only, Modify Current Date, and Add/Subtract Time — ensuring all event dates are clean, consistent, and correctly formatted for the destination platform.

07 · PUBLISH

API publish

The final API (Pabbly) node executes the publish request — sending the fully processed, AI-summarised, correctly formatted event data to the destination platform automatically.

08 · AUTOMATE

Fully automated pipeline

From RSS item to published event — the entire pipeline runs without any human involvement. New events are discovered, processed by AI, formatted, and published automatically 24/7.
