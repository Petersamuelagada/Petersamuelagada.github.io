The Project

Coaching teams managing multiple athletes face a constant challenge — tracking individual performance over time, spotting when an athlete needs attention, and generating consistent weekly reports without spending hours on manual data work.

This n8n automation handles the entire pipeline — from logging a training session to delivering a full weekly performance summary to the coaching team via Slack and email. OpenAI GPT acts as the analysis engine, interpreting performance data against historical records and generating actionable insights automatically.

Full n8n workflow — 4 phases: data ingestion, AI analysis, threshold checking, and weekly reporting

The 4 Automation Phases

Phase 1

Fetch & Combine Historical Data

When a training session form is submitted, the workflow stores the new record in Google Sheets, then fetches all prior historical records for that athlete. Current and historical data are combined into a single dataset — giving the AI agent full longitudinal context for accurate analysis.

Phase 2

Performance Analysis Agent

An OpenAI-powered Performance Analysis Agent processes the combined data — identifying trends, comparing session metrics, and generating written insights. Results are written back to Google Sheets automatically. The agent uses a structured output parser to ensure clean, consistent data output.

Phase 3

Check Performance Threshold

After analysis, a threshold check runs — evaluating whether the athlete's metrics breach predefined performance limits. If the threshold is breached, a Slack alert is sent immediately to the coaching team. If not, a standard email alert is sent. Coaches are only notified when action is genuinely needed.

Phase 4

Weekly Summary Schedule & Distribution

A separate scheduled trigger runs every week — fetching all weekly training data, grouping records by individual athlete, and passing each group to a Weekly Summary Agent powered by OpenAI. The agent generates a concise per-athlete performance summary which is sent to Slack and email automatically — giving the entire coaching team consistent weekly visibility without manual effort.
