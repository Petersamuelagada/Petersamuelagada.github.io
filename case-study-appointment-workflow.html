Appointment Status Update Workflow — 6-Branch Pipeline Automation

Built a multi-branch GHL workflow handling 6 appointment outcomes — Unable to Contact, Contacted, No Show, Showed, Sold, and Unqualified. Each branch auto-updates the pipeline stage, tags the contact, sends Thank You email + SMS, requests reviews, and nurtures leads. Zero manual work after setup.

The Project

The client was managing a high-volume appointment business and spending hours every day manually updating CRM stages, sending follow-up messages, and tracking lead outcomes. Every appointment had a different result — some prospects didn't answer, some showed up but didn't buy, some no-showed — and each situation required a completely different follow-up response.

With no automation in place, leads were falling through the cracks. No-shows weren't being re-engaged. Sold contacts weren't receiving onboarding. The sales team was wasting time on admin instead of selling. I was brought in to build a system that handles every outcome automatically — the moment an appointment status is updated in GHL, the right sequence fires immediately.

GHL workflow canvas — 6-branch appointment status automation

How It Works

🔀 The 6 Branches

Branch 01
Unable to Contact
  • Tag: "Unable to Contact"
  • Move to Re-Engage stage
  • SMS: "Hey, tried reaching you…"
  • Follow-up email after 24hrs
  • Auto-retry call task created
Branch 02
Contacted
  • Tag: "Contacted"
  • Move to Appointment Set
  • Confirmation SMS + Email sent
  • 24hr + 1hr reminder triggered
  • Add to reminder sequence
Branch 03
No Show
  • Tag: "No Show"
  • Move to No Show stage
  • SMS: "We missed you today…"
  • Reschedule email sent
  • 3-day re-engagement drip
Branch 04
Showed
  • Tag: "Showed – Not Sold"
  • Move to Showed stage
  • Thank you SMS sent
  • Nurture email sequence starts
  • Follow-up task created
Branch 05
Sold ✓
  • Tag: "Client – Sold"
  • Move to Won stage
  • Welcome SMS + onboarding email
  • Review request after 48hrs
  • Referral request after 7 days
Branch 06
Unqualified
  • Tag: "Unqualified"
  • Move to Lost stage
  • Remove from active sequences
  • Add to 90-day re-engage list
  • Internal notification sent
  • ⚡
    Trigger: Appointment Status Changes
    The workflow fires automatically the moment a GHL appointment status is updated — whether by a sales rep, calendar event, or inbound action. No manual trigger needed.
  • 🔀
    Branch Logic Routes the Contact
    A multi-condition branch reads the appointment outcome and sends the contact down the correct path — one of 6 fully independent branches, each with its own actions and timing.
  • 📊
    Pipeline Stage Auto-Updates
    Each branch immediately moves the contact to the correct CRM pipeline stage. No Show → No Show stage. Sold → Won. Unqualified → Lost. The pipeline always reflects reality in real time.
  • 🏷️
    Tags Applied for Segmentation
    Every contact gets the appropriate tag so future campaigns, filters, and automations can target them correctly. Sold clients never receive re-engagement emails. No-shows get a dedicated re-booking flow.
  • 📩
    SMS + Email Sent Automatically
    Each branch triggers personalised SMS and email messages timed to the outcome — immediate confirmation for booked contacts, warm welcome for sold clients, review requests at the right moment.
  • 🛑
    Smart Stops Prevent Over-Communication
    If a contact progresses (e.g. from No Show to Sold), the system detects the new status and stops the previous branch's sequence. No duplicate messages. No conflicting flows.
